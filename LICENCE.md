## ⚙️ Configuration

Settings are stored in `config.json` at `%APPDATA%\CyberpunkTrainer\config.json`.

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `menu_hotkey` | String | `"Insert"` | Key to toggle menu |
| `process_name` | String | `"Cyberpunk2077.exe"` | Target process |
| `safe_mode` | Boolean | `true` | Restricts risky features |
| `log_level` | String | `"info"` | `"debug"`, `"info"`, `"error"` |
